Box Model Demo

content-box vs border-box

Both boxes below declare the same width (200px), padding (20px), and border (8px). Inspect them in DevTools to see how their rendered width differs.

content-box: rendered width is 200 + 20*2 (padding) + 8*2 (border) = 256px
border-box: rendered width stays 200px, padding and border are taken out of the content area instead of added on top
